## الخدمات الخارجية

| الخدمة | الاستخدام | الشروط |
|---|---|---|
| Google Gemini API (`gemini-3.5-flash-lite`) | استخراج الادعاءات، التصنيف، ربط مقاطع المصادر بأجزاء الادعاء، اقتراح صياغة بديلة (يُعاد التحقق منها كاملة). الشرح المعروض للمستخدم مبني بقواعد ثابتة من النتيجة — **ليس مصدر دليل** | شروط Gemini API من Google. المفتاح في الخادم فقط. يُستخدم حاليًا مفتاح مجاني؛ يلزم مراجعة شروط استخدام البيانات في الخطة المجانية قبل أي إطلاق عام |
| Quranpedia (API + ملفات رسمية) | مصدر القرآن والتفسير وأسباب النزول | الاستخدام داخل التطبيق بلا نسبة إلزامية؛ إعادة النشر كمجموعة بيانات تتطلب النسبة والرابط والإصدار؛ 120 طلب/دقيقة، 10,000/يوم لكل IP |
| الدرر السنية | **لا يُستخدم** (محجوب بقرار سياسة) | — |
| Render | استضافة العرض الحي (خطة مجانية) | شروط Render |
| GitHub | استضافة المستودع | شروط GitHub |
